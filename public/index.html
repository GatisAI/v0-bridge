TROUBLESHOOTING
Kalau belum jalan.
Kenapa key hasil generate ditolak401?
Generate hanya membuat calon key. Masukkan ke GATEWAY_API_KEY atau GATEWAY_KEYS_JSON, simpan untuk Production, lalu redeploy. Gunakan domain deployment terbaru, bukan deployment lama.
Kenapa setup masih muncul setelah redeploy?
Periksa key v0, gateway key min24karakter, Redis REST URL HTTPS + token, dan MODELS_JSON yang valid. Status hanya mengecek format/keberadaan konfigurasi, bukan menguji koneksi provider. Jangan mengganti STATE_NAMESPACE saat mau resume sesi lama.
Bagaimana revoke atau menambah beberapa key?
Gunakan GATEWAY_KEYS_JSON dengan stable ID: {"main":"key1","friend":"key2"}. Hapus entry untuk revoke, ganti nilai tanpa mengubah ID untuk rotate, lalu redeploy. Mapping sesi mengikuti ID. Deployment lama dan request in-flight tidak otomatis dicabut; lindungi/hapus deployment lama.
Kenapa muncul409,429,503 atau504?
409: sesi aktif/diverged/pending. 429: rate limit atau safeguard. 503: konfigurasi/Redis gagal. 504: timeout; generasi mungkin masih berjalan dan ditagih di v0. Periksa chat v0 sebelum mencoba lagi—jangan blind retry.
Bisa mengubah env dari landing setelah setup?
Tidak. Landing tidak membaca kembali atau mengubah secret server. Setelah setup lengkap, ENV Generator disembunyikan. Perubahan berikutnya dilakukan lewat Vercel. PIN hanya melindungi generate calon key; bukan dashboard admin dan bukan aktivasi key.
